# Extended syntax

GitHub alerts, emoji shortcodes, highlight, superscript and subscript, and definition lists. Each one
renders in the preview and in every export (HTML, Word, OpenDocument, PDF). Compare the preview with
*File: Export Preview to PDF…* to see the same construct in both.

## Alerts

> [!NOTE]
> Useful information that users should know, even when skimming.

> [!TIP]
> Helpful advice for doing things better or more easily.

> [!IMPORTANT]
> Key information users need to know to achieve their goal.

> [!WARNING]
> Urgent info that needs immediate user attention to avoid problems.

> [!CAUTION]
> Advises about risks or negative outcomes of certain actions.

> An ordinary block quote stays an ordinary block quote.

## Emoji

Ship it :rocket: once the tests pass :white_check_mark: and the coffee is ready :coffee:.
An unknown shortcode stays as typed: :not-an-emoji:. A time such as 10:30:00 is not an emoji.

## Highlight, superscript, subscript

- ==Highlighted text== in the middle of a sentence.
- Einstein wrote E = mc^2^, and 2^10^ is 1024.
- Water is H~2~O and carbon dioxide is CO~2~.
- Strikethrough: ~~two tildes~~ or a ~single~ pair standing apart. Attached to the word before it, a
  single pair is a subscript instead (H~2~O above).

## Definition lists

Preview
: The rendered view of a Markdown file, beside or instead of the source.

Split
: Editor and preview side by side, scrolled together.
: A second definition for the same term.

Front matter
: The YAML or TOML block at the very top of a file.
